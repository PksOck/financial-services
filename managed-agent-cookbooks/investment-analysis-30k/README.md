### Podrobnosti vsakega instrumenta

#### 1. MVOL — iShares Edge MSCI World Minimum Volatility UCITS ETF
- **Kaj je:** Globalne delnice z matematično najnižjo volatilnostjo iz 23 razvitih trgov
- **Zakaj:** Delnice, ki manj padejo v krizah — defenzivni sektorji (komunale, zdravje, prehrana)
- **TER:** 0,30 % letno
- **Pričakovani donos:** 6–8 % letno
- **Max drawdown 2020 (COVID):** –12 % (vs. –25 % za navaden MSCI World)
- **Max drawdown 2008:** –30 % (vs. –42 % za navaden MSCI World)
- **Dostopnost:** Xetra, Euronext Amsterdam, LSE — vsi DEGIRO/IBKR

#### 2. VHYL — Vanguard FTSE All-World High Dividend Yield UCITS ETF
- **Kaj je:** ~1.800 podjetij z nadpovprečno dividendno donosnostjo globalno
- **Zakaj:** Podjetja z visoko dividendo so pogosto zrelejša, manj tvegana — finančna stabilnost
- **TER:** 0,29 % letno | Dividendna donosnost: ~3,5–4,5 %
- **Pričakovani donos:** 6–8 % (dividende + kapitalska rast)
- **Max drawdown 2020:** –19 % (nižje kot rast ETF-i)
- **Opomba:** Distribucijski razred — izplačuje dividende (4x letno) → davčna obveznost vsako leto

#### 3. IEAC — iShares Core EUR Corp Bond UCITS ETF
- **Kaj je:** ~2.500 EUR-denominiranih korporativnih obveznic z oceno A/BBB
- **Zakaj:** Stabilni donos, nizka volatilnost, negativna korelacija z delnicami v krizah
- **TER:** 0,20 % letno
- **Trenutna donosnost do dospetja (YTM):** ~3,8–4,5 %
- **Max drawdown 2022 (obrestna kriza):** –16 % (obveznice so upadle ob dvigu obrestnih mer)
- **Opomba:** Obveznice so tvegane pri hitrem dvigu obrestnih mer — upoštevaj!

#### 4. IEGA — iShares Core EUR Govt Bond UCITS ETF
- **Kaj je:** EUR državne obveznice (Nemčija, Francija, Italija, Španija itd.)
- **Zakaj:** Najvarnejša oblika obveznic — varno pribežališče v krizi, delnice padejo, te rastejo
- **TER:** 0,09 % letno (med najcenejšimi)
- **Trenutna donosnost:** ~2,8–3,5 %
- **Max drawdown 2022:** –18 % (obrestna kriza je prizadela vse obveznice)
- **Pozitivno:** V delniških krizah (2008, 2020) te so rastle ali ostale stabilne

#### 5. IWDP — iShares Developed Markets Property Yield UCITS ETF
- **Kaj je:** Nepremičninska investicijska podjetja (REIT) v razvitih trgih
- **Zakaj:** Inflacijska zaščita, stabilni najemninski donosi, diverzifikacija
- **TER:** 0,59 % letno
- **Dividendna donosnost:** ~3–5 % + kapitalska rast
- **Pričakovani skupni donos:** 6–9 %
- **Opomba:** REIT-i so bolj volatilni kot obveznice — uvrstimo jih med "zmerna tveganja"

#### 6. XEON — Xtrackers EUR Overnight Rate Swap UCITS ETF
- **Kaj je:** Sled za ECB overnight obrestno mero (ESTR)
- **Zakaj:** Gotovina z donosom — varno, likvidno, brez kreditnega tveganja
- **TER:** 0,10 % letno
- **Trenutni donos:** ~2,8–3,5 % (sledi ECB politiki)
- **Max drawdown:** Praktično 0 % — ne more pasti
- **Vloga:** Likvidnostna rezerva za dokupoanje ob padcih + stabilizator portfelja

## Tveganja, ki ostajajo

### 1. Obrestno tveganje (NAJVEČ tveganja za ta portfelj)
Portfelj ima 40 % v obveznicah. Če ECB dvigne obrestne mere hitro (kot 2022), **obveznice padejo**.
- Blažilec: XEON in delniška komponenta blažita padec
- Horizont: Obveznice okrevajo, ko obrestne mere stabilizirajo

### 2. Inflacija
- 5,5 % donos pri 3 % inflaciji = 2,5 % realni donos — skromen, a pozitiven
- REIT in delnice ščitijo pred inflacijo bolje kot obveznice

### 3. Valutno tveganje
- MVOL in VHYL imata izpostavljenost USD/JPY/GBP — EUR vlagatelj nosi valutno tveganje
- IEAC in IEGA sta 100 % EUR — brez valutnega tveganja
